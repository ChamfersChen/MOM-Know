# 知识库配置弹窗分栏

## 目标

将知识库基础信息、权限和检索参数集中到同一个配置入口，减少检索测试页面的信息干扰，并明确区分保存与关闭弹窗。

## 验收标准

- “配置知识库”弹窗包含“基础信息”“权限配置”“检索配置”三个 TAB，详情页入口使用“配置”文案。
- 原检索测试右侧的检索参数表单迁入编辑弹窗，检索测试保留完整测试区域。
- 点击“保存”同时保存知识库信息和检索参数，成功后弹窗保持打开。
- 只有“关闭”、右上角关闭按钮或标准键盘关闭操作退出弹窗；点击遮罩不关闭。
- 弹窗宽度适配三类配置，并在窄屏下保持可滚动和可操作。
- 权限范围越界警告位于读取和管理配置区块之前，弹窗内不提供删除知识库入口。
